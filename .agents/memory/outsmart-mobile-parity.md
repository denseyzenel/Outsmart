---
name: OUTSMART mobile parity
description: Rules for keeping the native app aligned with the user-approved website experience.
---

The website is the source of truth for approved gameplay wording, outcome messages, Xavi remarks, scoring language, and access behavior. Mobile work should adapt presentation to native constraints without inventing replacement copy.

**Why:** The user explicitly rejected mobile-specific result wording and asked to keep the website version, which they considered the correct product voice.

**How to apply:** Before changing mobile gameplay or monetisation copy, compare the corresponding website flow. Preserve its wording and behavior unless the user specifically requests a cross-platform copy change.
